# Morrow — Social Media Website

Morrow is a simple multi-page social media prototype made with HTML, CSS.

## Pages
- `index.html` — Home feed and create-post box
- `pages/login.html` — Login form demonstration
- `pages/signup.html` — Signup form demonstration
- `pages/profile.html` — Sample profile and edit profile feature
- `pages/explore.html` — Interest cards
- `pages/about.html` — Project information and privacy note

## Folder structure
```text
morrow/
├── index.html
├── pages/
│   ├── login.html
│   ├── signup.html
│   ├── profile.html
│   ├── explore.html
│   └── about.html
├── css/style.css
├── js/script.js
└── README.md
```

## How to run
1. Extract the ZIP file.
2. Open the `morrow` folder in Visual Studio Code.
3. Open `index.html` in your browser, or use the Live Server extension.
4. Use the navigation links to visit each page.

## Features
- Links between pages
- Create a post on the home page
- Like and unlike posts
- Character counter
- Demo login and signup forms
- Edit profile name and bio
- Responsive layout for phones and computers

## Technologies
- HTML creates page content.
- CSS controls colors, spacing, and layout.
- JavaScript handles button clicks and form interactions.

## Privacy and limitations
This is a frontend school project only. It has no backend, database, or API. Login and signup do not create or verify real accounts. Posts and profile changes are not saved permanently. Do not enter a real password or private information.

## Make it your own
Change the sample posts, profile details, and colors. Read the code and make sure you understand it before presenting it in class.
